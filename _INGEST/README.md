# Source ingestion inbox

- `MARKDOWN/`: default saved-webpage source inbox. Say “Ingest my new markdown sources.”
- `PDF/`: PDF/newspaper inbox, processed under its separate protocol.

Ingestion copies files; originals stay here unchanged. Protocols: `00_ADMIN/MARKDOWN_SOURCE_INGESTION_PROTOCOL.md` and `00_ADMIN/NEWSPAPER_INGESTION_PROTOCOL.md`. Hashes/source records prevent repeated ingestion.
