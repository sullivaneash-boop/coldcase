# AI workspace

All material here is analysis, not evidence.

- `generated_hypotheses/`: speculative outputs, prominently labeled.
- `source_comparisons/`: AI comparisons with source IDs and locators.
- `prompts/`: exact prompts and input manifests; avoid duplicating restricted source content.
- `validation_queue/`: candidate assertions and citation checks awaiting human review.

Use `00_ADMIN/templates/AI_ANALYSIS_TEMPLATE.md`. Preserve raw output separately from human corrections. Never register model-generated output as independent evidentiary support. Human analysis belongs in `11_ANALYSIS/`.
