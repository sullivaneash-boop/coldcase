# AI-GENERATED ANALYSIS IS NOT EVIDENCE.

Store speculative AI hypotheses here, never in original-source storage. Use the AI analysis template in `00_ADMIN/templates/`. Record model, run time, prompt, input source IDs, exact input file hashes when available, output, limitations and human review state.

Citations generated by AI must be checked against the actual source and locator. Move proposed claims into the validation queue; only a documented human review can add a sourced claim to the research registers. Hypotheses do not establish identity, guilt or factual truth.
