# Source rating system

| Class | Description | Assessment guidance |
| --- | --- | --- |
| A | Primary documentary evidence | Inspect authenticity, completeness, authorship and context. An official document can contain errors or reported allegations. |
| B | Direct firsthand account | Record opportunity to observe, recording circumstances and delay. Memory can change. |
| C | Strong contemporaneous journalism | Record attribution, editorial provenance and proximity to events. |
| D | Later professional journalism | Check retrospective sourcing and dependence on earlier reports. |
| E | Secondary research | Trace citations to original material where possible. |
| F | Community/user-generated information | Use as leads; seek independent support. |
| G | Unsupported/unverified information | Preserve provenance and uncertainty; do not present as established. |

Reliability class does NOT automatically determine whether an individual claim is true. Classification is a documented human assessment, not a numeric truth score. Leave the class blank pending review. Explain classification and changes in source notes. Evaluate each claim independently, including independence of corroboration and contrary material.

`primary_or_secondary` describes the source's relationship to the subject; `knowledge_basis` describes the origin of an account. A primary record can quote hearsay. Mixed documents may require claim-level knowledge-basis annotations in `claim_sources.csv`.
